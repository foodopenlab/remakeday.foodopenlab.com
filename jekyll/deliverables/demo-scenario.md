# 11. 시연 시나리오

[15. 최종산출물]({{ '/showcase/screens/' | relative_url }})의 화면 흐름을 시연 대본으로 옮긴 것입니다. 한 판(5회차)을 실제로 끝까지 하면 40~80분이 걸리므로(휴먼테스트 실측 48~78분), 시연은 **1회차를 끝까지 보여 주고** 마지막 두 단계는 미리 끝내 둔 판의 회고로 대신합니다. 전체 약 15분.

## 준비

| 항목 | 내용 |
|---|---|
| 접속 | `remakeday.com`, 데스크톱 브라우저 1280×800 이상. 모바일 웹도 되지만 시연은 데스크톱이 편하다 |
| 계정 | 구글 계정 로그인. 하루 판 수 한도가 있으므로 시연 전에 오늘 판을 다 쓰지 않았는지 확인 |
| 미리 끝낸 판 | 5회차를 완주한 판 하나. 회고는 `/harness/{판 ID}`로 다시 열 수 있으므로 ID를 적어 둔다 |
| 소리 | 관리자 방송은 음성으로도 나온다. 오른쪽 위 음성·BGM 스위치를 켠 상태로 시작 |
| 모델 | 공개 운영 구성은 Core Sonnet 5 · NPC Haiku 4.5. 장면 전환(planner)에 약 10초, NPC 답변에 약 2초 걸린다 — 기다리는 동안 말할 거리를 아래 "짚어 줄 것"에 뒀다 |

## 단계별 대본

### 1. 진입 (1분) — [화면]({{ '/showcase/screens/#entry' | relative_url }})

| | 내용 |
|---|---|
| 방문자가 하는 것 | 랜딩에서 로고 아래 두 줄을 읽고 구글로 로그인한다. `/play` 진입 화면의 규칙 세 줄을 읽고 시작을 누른다 |
| 시스템이 하는 것 | 로그인 없이 `/play`에 오면 「로그인이 필요하다」 전용 화면, 오늘 판 수를 다 썼으면 「오늘은 여기까지」 화면으로 막는다. 로그인하면 새 판을 만든다 |
| 짚어 줄 것 | 설치·튜토리얼 없이 30초 안에 시작한다는 것. 과잉 사용 방지 허들은 오류 배너가 아니라 게임 말투의 화면으로 나온다는 것. 규칙은 「하루 6장면 · 대화 8회 · 밤에 쓴 글은 다음 밤에 이어진다」 세 줄이 전부라는 것 |

### 2. 아침 (1분) — [화면]({{ '/showcase/screens/#morning' | relative_url }})

| | 내용 |
|---|---|
| 방문자가 하는 것 | 「7시 12분. 눈을 뜬다.」와 남은 대화 8회를 확인하고 낮으로 넘어간다 |
| 시스템이 하는 것 | 회차별 아침 문장을 보여 주고, 2회차부터는 어젯밤 건 규칙을 「오늘 세계에 걸린 규칙」으로 쌓아 보여 준다 |
| 짚어 줄 것 | 매 회차 같은 문장으로 시작하지만 대화 예산이 8 → 4로 줄고, 아침 문장에 한 줄씩 무언가가 붙는다는 것. 미리 끝낸 판의 5일째 아침 화면을 잠깐 보여 주면 규칙이 쌓인 모습이 한눈에 들어온다 |

### 3. 낮 — 대화 (4분) — [화면]({{ '/showcase/screens/#day' | relative_url }})

| | 내용 |
|---|---|
| 방문자가 하는 것 | 관리자 방송을 듣고, 장면 그림과 서술을 읽고, 인물 카드(채연·민석·은상·준) 중 하나를 골라 한 줄로 묻는다. 두세 장면을 넘기며 질문 2~3개를 쓴다. 단서 기록을 한 번 열어 본다. 원숭이손 제안이 오면 받을지 거절할지 고른다 |
| 시스템이 하는 것 | 장면이 바뀔 때 방송이 화면을 덮고 음성으로 나온다. 질문 하나에 대화 1회를 차감하고, 같은 장면에서 같은 인물에게는 다시 묻지 못하게 한다. NPC는 인물의 성격과 그날 본 것만으로 짧고 쉬운 말투로 답한다. 본 것·들은 것은 출처(장면에서 관찰 / 이미지에서 관찰 / 발언을 들음)와 함께 단서 기록에 자동으로 쌓인다. 6번째 장면의 소등 방송 뒤 「밤이 온다」 버튼이 나온다 |
| 짚어 줄 것 | NPC 답은 대본이 아니라 모델이 그 자리에서 만든 것이고, 숨은 진실은 NPC에게 주지 않는다는 것. 「발언을 들음」 카드에 「말했다는 사실의 기록이며 내용의 참 여부는 별도」라고 적힌 이유 — 인물의 말이 사실인지는 플레이어가 판단한다. 원숭이손은 규칙 하나를 거는 대신 보이지 않는 대가가 따른다는 것. 1일째에 단서가 40건 넘게 쌓인다는 것 |

### 4. 밤 — 서술과 채점 (3분) — [화면]({{ '/showcase/screens/#night' | relative_url }})

| | 내용 |
|---|---|
| 방문자가 하는 것 | 「오늘은 무슨 상황이었나요? 왜 멸망하나요?」에 오늘 본 것으로 두세 문장을 자기 말로 쓴다. 기록 패널을 펼쳐 참고하면서 써도 된다. 「이렇게 이해했는데, 맞아?」 화면에서 AI가 쪼갠 주장 목록을 확인하고 보낸다 |
| 시스템이 하는 것 | 서술을 문장 단위 주장으로 정리해 되묻는다(틀렸으면 한 번 고칠 수 있다). 채점을 기다리는 동안 오늘 나눈 대화를 다시 흘려 보낸다. 결과는 원인·동기·정체 칸별로 한 줄씩, 세계와 닿지 않은 주장 개수와 함께 돌아온다 |
| 짚어 줄 것 | 밤에는 선택지가 없고 글로 쓴다는 것. 확인 단계가 있는 이유 — AI가 멋대로 해석한 채로 채점되지 않게 사람이 보내기 직전에 본다. 쓴 글은 다음 밤에 그대로 다시 열려 이어 쓸 수 있다는 것. 첫 밤 점수는 낮은 게 보통이라는 것(휴먼테스트 1회차 0~55점) |

### 5. 멸망 (1분) — [화면]({{ '/showcase/screens/#doom' | relative_url }})

| | 내용 |
|---|---|
| 방문자가 하는 것 | 아무것도 하지 않고 본다 |
| 시스템이 하는 것 | 이해도와 상관없이 세계가 멸망한다. 짧은 문장이 한 줄씩 떠오르고 관리자 목소리가 겹친다. 마지막 줄이 그날 밤의 단서다 |
| 짚어 줄 것 | 멸망은 실패가 아니라 루프의 구조라는 것. 마지막 줄의 단서는 회차마다 달라서 다섯 밤을 모으면 윤곽이 드러난다는 것. (4·5회차 단서는 결말에 가까우므로 시연에서는 보여 주지 않는다) |

### 6. 신의 개입 (3분) — [화면]({{ '/showcase/screens/#god' | relative_url }})

| | 내용 |
|---|---|
| 방문자가 하는 것 | 오늘 있었던 일을 세 번까지 묻는다(예: 「오늘 트럭이 왔어?」). 답의 「근거 보기」를 펼친다. 규칙 후보 셋 중 하나를 고르거나 직접 써서 「해석 미리보기」를 본 뒤 적용한다 |
| 시스템이 하는 것 | 「맞다 · 아니다 · 그건 알 수 없다」로 답하고 공개된 관찰 기록 중 근거를 붙이며 내일 확인할 방향을 알려 준다. 오늘의 관찰에서 규칙 후보를 최대 3개 뽑아 행동·이유·확인·연결 근거 수를 붙인다. 적용하면 「세계에 규칙이 걸렸다」 |
| 짚어 줄 것 | 이 목소리는 오늘 일어난 일만 알고 숨겨진 진실은 받지 않는다는 것 — 그래서 「알 수 없다」가 자주 나온다. 규칙이 다음 하루의 세계를 실제로 바꾼다는 것(2회차 아침에 걸린 규칙이 보이고, 낮 장면에서 그 행동이 일어난다). 직접 쓴 규칙은 AI가 어떻게 실행할지 미리보기로 먼저 확인한다는 것 |

### 7. 다섯 번째 밤 (2분) — [화면]({{ '/showcase/screens/#final' | relative_url }})

| | 내용 |
|---|---|
| 방문자가 하는 것 | 시연 판은 여기서 멈추고, 미리 끝낸 판의 회고(`/harness/{판 ID}`)를 연다. 「다섯 번째 밤, 마지막 기록」 카드와 회고 「너의 추리는 이렇게 걸어왔다」를 본다 |
| 시스템이 하는 것 | 최종 이해도를 상황(70점)·정체(30점)로 나누고, 원인·동기·정체 칸마다 맞춘 칸만 진실을 연다. 못 맞춘 칸은 「?」와 다음 판에서 확인할 것 한 줄. 회고에는 밤마다 열린 단서와 이해도, 진실과 내 기록 대조, 접힌 개발 데이터(규칙 준수 여부·원숭이손의 대가·하네스 개입 횟수)가 있다 |
| 짚어 줄 것 | 점수와 상관없이 다섯 번째 밤에 이야기가 끝난다는 것. 진실은 맞춘 만큼만 열리고 서버가 걸러서 보내므로 네트워크 응답에도 스포일러가 없다는 것. 「개발 데이터」 접힘은 AI가 실제로 어떻게 움직였는지 확인하는 곳이라는 것. 「다시 시작」은 지난 판의 칸별 결과를 들고 새 판을 연다는 것 |

| 단계 | 예상 |

| 1. 진입 | 1분 |
| 2. 아침 | 1분 |
| 3. 낮 — 대화 | 4분 |
| 4. 밤 — 서술과 채점 | 3분 |
| 5. 멸망 | 1분 |
| 6. 신의 개입 | 3분 |

시간이 더 있으면 2회차 아침과 첫 낮 장면까지 이어서, 어젯밤 건 규칙이 실제로 세계를 바꾸는 장면을 보여 줍니다(+3분).

## 자주 받는 질문

- **NPC가 「몰라」만 하면?** — 그 인물이 그날 실제로 본 것이 아니면 모른다고 답하도록 만들었다. 본 것을 바탕으로 구체적으로 묻는 편이 낫다(「오늘 아침에 누구 봤어?」).
- **신의 답이 「알 수 없다」만 나오면?** — 공개된 관찰 기록에 근거가 없으면 그렇게 답한다. 예시 질문 칩을 쓰거나, 그날 방송·소등 뒤 일에 대해 묻는다.
- **점수가 왜 이렇게 낮나?** — 첫 밤은 대부분 낮다. 답안에 직접 쓴 문장만 채점되고, 기록을 요약하지 않고 인과로 잇는 문장이 점수를 받는다.
