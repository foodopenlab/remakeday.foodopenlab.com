# 9. 시나리오 테스트

이 장은 v1이 **실제로 동작하는지**를 어떻게 확인했는지 다룹니다.
오픈 조건은 기능 수가 아니라 절대 방어선 ①~⑤가 끝에서 끝까지 도는가 하나이며,
알파 → 기능 동결 → 릴리스 세 게이트와 매일 1회 도는 회귀 시나리오 10종으로 그것을 확인합니다.
이 제품의 P0에는 게임 진행 불가뿐 아니라 "판정 로그 유실"이 들어갑니다 — 로그가 산출물이기 때문입니다.
LLM 모델 자체의 평가는 별도 페이지에서 Exp 1의 러너·게이트·결정을 요약합니다.
